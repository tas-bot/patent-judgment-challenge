# 特許実務力ブラインド判定チャレンジ（無料・個別スコア返送）

**このリポジトリは課題の保管庫です。参加・提出は公開ページからお願いします。**

→ **参加ページ: <https://lab.connectivebyte.com/content/20-patent-judgment-challenge/>**

実際の日本の特許出願を題材に、あなた自身の審査判断（処分・適用条文・引用文献・根拠段落・理由）を提出すると、**実際の特許庁が発行した初回拒絶理由通知との一致度**を機械採点し、カテゴリ別スコアを**提出者本人にのみメールで返送**します。

- 参加費: **無料**
- 所要の目安: 2〜4時間
- 対象: 弁理士、特許事務所スタッフ、知財担当者、元・現審査官、学生、誰でも
- 技術分野: **10件の実案件**（撮像素子・電池材料・カテーテル・三次元造形・凍結食品・太陽光予測・充電計画など多分野）。複数ケースの提出が可能です
- 提出方法: **メール1通**（`contact@tokyo-ai-solutions.co.jp` 宛・プレーンテキストの記入テンプレート）。GitHubアカウントは不要です

## このリポジトリの内容

- [`task/claim_and_breakdown.md`](task/claim_and_breakdown.md) — 課題ケース1（請求項1・参考分説・引用候補文献プール）
- [`task/ai_draft.md`](task/ai_draft.md) — 第2部のAI下書き（ケース1・パイプライン生成）
- [`task/submission-template.txt`](task/submission-template.txt) — メール提出テンプレート（ケースID欄に提出するケースを記入）
- [`RUBRIC.md`](RUBRIC.md) — 採点ルーブリック（基準のみ公開・正解は非公開）
- ケース一覧とケース2〜10の課題素材・AI下書きは公開ページに掲載しています

## 開示方針（明示）

- **公開するのは採点基準のみです。** 実際の正解（初回OAの処分・条文・引用文献・根拠段落）は公開しません
- **個別情報は公開しません。** 提出内容・スコア・ハンドルの一覧やランキングは作成しません。スコアは提出者本人へのメール返送のみで、公開コメントには書きません
- ランキングの公開は、データが蓄積して統計的な価値が出た時点で方針を再検討します
- 採点結果の集計・研究利用はハンドル単位の匿名のまま行います

## 限界の明示（誠実な開示）

- **各ケースは1回の判断（ケースあたり n=1）です。** 単一ケースのスコアには大きなノイズがあり、1回の得点で実務力を断定できません。現在10ケースを提供しており、複数ケースを提出するとケース別スコアに加えてケース数つきの平均を返送します（平均の信頼性はケース数に漸増します）
- 根拠段落の一致は（文献番号, 段落番号）ペアの集合照合であり、**意味上の支持の判定ではありません**
- 第1部→第2部の順守は自己申告です
- 本チャレンジは法的助言・審査官の代替ではありません
- **出題ケースは実案件のため、引用文献・適用条文・処分は公開情報（引用文献等情報・審査経過）から発見・推定可能な項目があります。** 詳細は RUBRIC.md「正解の非開示と発見可能性の明示」参照。機械照合が完全なブラインドであるとは主張しません。同一ケースの経過情報を参照した場合は提出文に明記してください

## ルール

- 1ハンドル・1ケースにつき **1回のみ提出**（再提出による総当たりは採点しません）。**複数ケースの提出は歓迎します**（1メールにつき1ケース、ケースIDをご記入ください）
- 公開情報（J-PlatPat 等の公報、審査基準・審査便覧）の参照は自由です
- ハンドルは任意の匿名名。実名・連絡先は不要です（返送用のメールアドレスのみ伺います）
- 採点に使用する実際のOA情報の開示要求には応じられません
