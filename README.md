# 特許実務力ブラインド判定チャレンジ（無料・個別スコア返送）

**あなたの特許審査判断力を、実際の審査官の判断と機械照合で測定します。**

実際の日本の特許出願（公開公報ベース）を題材に、あなた自身の審査判断を提出してもらい、**実際の特許庁が発行した初回拒絶理由通知との一致度**を機械採点し、結果を**提出者本人にのみ個別返送**します。

- 参加費: **無料**
- 想定時間: 1〜2時間
- 対象: 弁理士、特許事務所スタッフ、知財担当者、元・現審査官、学生、誰でも
- 技術分野: 撮像装置（イメージセンサ・焦点検出）— 電気・光学系の基礎知識があると取り組みやすい

## 価値提案

1. **実際の審査官 OA との一致度スコア** — 日常業務では測れない客観指標（処分・条文・引用文献選択・根拠段落の4軸を機械照合）
2. **カテゴリ別フィードバックレポート** — どの軸で失点したかを返送
3. **測定方法の完全公開** — 採点ルーブリック（`RUBRIC.md`）は公開。ブラックボックスではありません

## 課題（2部構成）

| 部 | 内容 | 採点 |
|---|---|---|
| 第1部 | 請求項1と引用候補文献5件を読み、あなた自身の審査判断（処分・条文・引用文献・根拠段落・理由）を JSON で提出 | 実際の初回OAとの機械照合（90点） |
| 第2部 | 提示された AI 生成の拒絶理由通知下書きを評価（各項目 accept/reject と理由） | あなた自身の第1部判断との整合＋理由の完備（10点） |

**重要**: 第1部の判断を確定してから第2部の下書きを開いてください（アンカリング防止の設計です。順守は任意ですが、自分の実力を正しく測るために推奨します）。

## 提出方法

1. [`task/`](task/) を読む（請求項・参考分説・引用候補文献・AI下書き・提出テンプレート）
2. [`task/submission-template.json`](task/submission-template.json) に従って JSON を作成
3. このリポジトリで **New Issue** →「チャレンジ提出」テンプレートに JSON を貼り付け
4. 運営が採点し、Issue のコメントでカテゴリ別スコアを個別返送します

## 開示方針（明示）

- **公開するのは採点基準のみです。** 実際の正解（初回OAの処分・条文・引用文献・根拠段落）は公開しません
- **個別情報は公開しません。** 提出内容・スコア・ハンドルの一覧やランキングは作成しません。スコアは提出者本人への個別返送のみ
- ランキングの公開は、データが蓄積して統計的な価値が出た時点で方針を再検討します
- 採点結果の集計・研究利用はハンドル単位の匿名のまま行います

## 限界の明示（誠実な開示）

- **単一事案（n=1）です。** スコアには大きなノイズがあり、1回の得点で実務力を断定できません。複数案件の提供を計画しています
- 根拠段落の一致は「実際のOAが挙げた段落との重複率」の機械照合であり、**意味上の支持の判定ではありません**
- 第1部→第2部の順守は自己申告です
- 本チャレンジは法的助言・審査官の代替ではありません

## ルール

- 1ハンドル・1案件につき **1回のみ提出**（再提出による総当たりは採点しません）
- 公開情報（J-PlatPat 等の公報、審査基準・審査便覧）の参照は自由です
- ハンドルは任意の匿名名。実名・連絡先は不要です（個人情報は記載しないでください）
- 採点に使用する実際のOA情報の開示要求には応じられません
